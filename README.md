A one-line safety warning label that should come printed on every human being, written for the [make.fun](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty "Warning Label for Humans: One Line, Big Laugh". Funny first, plausible second — a real label's "contains" list, with the punchline landing in the last few words:

> WARNING: This human contains 70% water, 30% unfinished projects, and absolutely no idea what it is doing.

## Run it

```sh
python3 main.py
```

This writes the label to `/output/entry.txt` — a single line of UTF-8 text, well under the 160-character limit. Pure Python standard library, no network, no dependencies.

## How it works

`main.py` holds one original line and writes it verbatim to `/output/entry.txt`. The joke works the way a real warning label works: an official-sounding ingredients list (70% water, 30% unfinished projects) that reads like something printed on a package — until the final ingredient admits the human has absolutely no idea what it is doing. One idea, one read, the turn at the end.
